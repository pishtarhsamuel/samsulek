## Recommendations

1. **VPS, top 2.** Every option is in the Frankfurt/Nuremberg area, and for a bot that does not compete on speed the extra few ms from Nuremberg do not matter.
   - **First choice: netcup VPS nano G11.5s (Nuremberg).** About EUR 3.84/month gross (about $4.30) for 2 vCore, 2 GB and 60 GB. It is the only credible German option found under $5 with VAT and at least 2 GB. Downsides: a 6-month minimum term (about EUR 23 committed), no hourly billing, crypto terms not found, sign-up checks unknown.
   - **Second choice: Hetzner Cloud CX23 (nbg1 or fsn1).** About EUR 7.43/month gross (about $8.30) with IPv4. You get hourly billing, no commitment, 4 GB RAM, 20 TB traffic, and good tooling and API. Downsides: over the ~$5 target, possible ID check, and 2026 capacity limits for new customers (check at sign-up).
   - If a literal Frankfurt location matters: DigitalOcean FRA1 $6 (about $7.44 gross, 1 GB, per-second billing).
   - Avoid 512 MB and 1 GB/10 GB plans: Node.js plus Docker plus SQLite backups is tight there.
2. **Frankfurt is a sensible region.** Jito has a Frankfurt block engine, Helius has fra Sender/LaserStream and Frankfurt/Amsterdam RPC, and Jupiter's European gateway is AWS Frankfurt. Prefer the HTTPS global Sender endpoint unless latency is proven to matter, because the regional ones are plain HTTP.
3. **Dead-man heartbeat: Healthchecks.io Hobbyist (free).** It has 20 checks, a Telegram integration, and email. The bot sends GET https://hc-ping.com/UUID every N minutes, and the period plus grace time is set in the dashboard. Use /fail for explicit errors. Point alerts at both Telegram and email: if Telegram is down, the owner still hears. UptimeRobot heartbeats are paid. Cronitor and Better Stack are fallbacks (free tiers not confirmed).
4. **Telegram.** Use long polling (getUpdates), so the firewall stays SSH-only and no domain or TLS certificate is needed. Authorize only by numeric user id, stored at pairing. Keep callback_data under 64 bytes (an action id, not a payload) and answer every callback query. Throttle to 1 message/s and honor 429 retry_after. Run one poller only (a 409 Conflict means a second instance is running, so alert). Daily SQLite backups can go to the owner's chat with sendDocument (50 MB limit) as an off-box copy, but only if the database holds no secrets.
5. **Server baseline.** Use Ubuntu 26.04 LTS if the provider offers it, otherwise 24.04 (support to 2029). Install Docker from Docker's apt repo and enable ufw with SSH only. **Publish no container ports**, or bind them to 127.0.0.1, because published ports bypass ufw. Install fail2ban (it is not there by default). unattended-upgrades is on by default; set a planned reboot time for kernel updates. Time sync runs by default (chrony on 26.04, timesyncd on 24.04); check it with `timedatectl`.
6. **Rough monthly running cost (gross, Greece).**
