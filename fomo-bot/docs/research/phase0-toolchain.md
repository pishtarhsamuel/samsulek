## Incidents and lessons

Publish times below are registry `time` fields (HIGH). Unpublish times are not in the registry.

1. **@solana/web3.js, 2024-12-03** (GHSA-jcxm-7wvp-g6p5, CVE-2024-54134; HIGH, advisory record from raw.githubusercontent.com/github/advisory-database). A publish-access account was compromised; versions 1.95.6 (15:10:07Z) and 1.95.7 (15:20:23Z) were modified "to steal private key material and drain funds from dapps, like bots, that handle private keys directly". Advisory window 15:20-20:25 UTC; fixed in 1.95.8 (20:25:40Z); both versions unpublished. Advice: upgrade, rotate any authority or server keypairs. Our bot is exactly the affected class (holds a hot key).
2. **chalk/debug and 16 more, 2025-09-08** (HIGH for names, versions, advisory ids via npm advisory feed; payload not verified here). Malware advisories exist for chalk 5.6.1 (GHSA-2v46-p5h4-248w), debug 4.4.2 (GHSA-4x49-vf9v-38px, "contains malware after npm account takeover"), ansi-styles 6.2.2, supports-color 10.2.1, strip-ansi 7.1.1, ansi-regex 6.2.1, wrap-ansi 9.0.1, color-convert 3.1.1, color-name 2.0.1, is-arrayish 0.3.3, slice-ansi 7.1.1, error-ex 1.3.3, color-string 2.1.1, simple-swizzle 0.2.3, has-ansi 6.0.1, chalk-template 1.1.1, backslash 0.2.1, supports-hyperlinks 4.1.1. debug 4.4.2 published 13:12:39Z, chalk 5.6.1 13:13:05Z, both later unpublished. Relevance: `debug` is a direct dep of grammy (^4.4.3, excludes 4.4.2), telegraf (^4.3.4) and eslint (^4.3.2), whose ranges include 4.4.2.
3. **Shai-Hulud worm, 2025-09** (MEDIUM, CISA alert 2025-09-23 and GitHub blog, both seen via search). Self-replicating: stole credentials, sent them to an attacker endpoint and a public GitHub repo named "Shai-Hulud", then used victims' npm tokens to publish infected versions of their other packages; 500+ packages; GitHub says it was notified 2025-09-14. Advisory confirmed for @ctrl/tinycolor 4.1.1-4.1.2 (GHSA-qjqf-7j6f-82c4; published 2025-09-15 19:52Z and 20:13Z). GitHub's response plan (2025-09-22): publishing only with 2FA, short-lived (max 7 days) granular tokens, or trusted publishing; deprecate classic tokens and TOTP 2FA (MEDIUM). "Shai-Hulud 2.0" (late 2025) added destructive functionality and targeted CI (MEDIUM). npm 12.0.0 then blocked dependency install scripts by default (HIGH, F18).
4. **Solana typosquats, January 2025** (MEDIUM, Socket research via The Hacker News; malware advisories HIGH): solana-transaction-toolkit (GHSA-g7m3-jm2q-7jxp), solana-stable-web-huks (GHSA-qj6v-j8gh-5jc5), dexscreener (GHSA-r29w-7jf3-6f76) stole Solana private keys via Gmail SMTP, two drained up to 98% of wallets. A GitHub "pumpfun-bump-script-bot" repo imported one of them.
5. **Fake "solana-pumpfun-bot" GitHub repo, June-July 2025** (MEDIUM, SlowMist via Cointelegraph; advisory GHSA-m5fp-mv4p-cgp6 for crypto-layout-utils HIGH). Inflated stars/forks; its package-lock.json `resolved` link pointed to a GitHub-hosted malicious "crypto-layout-utils" tarball (not from the registry) that scanned for wallet files and keys and uploaded them. A batch of fork accounts spread variants.
6. **axios, 2026-03-31** (advisory GHSA-fw8c-xr5c-95f9 "Malware in axios", critical, HIGH; details MEDIUM via CSA Singapore AD-2026-002 and WSO2; CISA alert of 2026-04-20 seen as a title only). axios 1.14.1 (00:21:58Z) and 0.30.4 (01:00:57Z) were published from a hijacked maintainer account, added dependency plain-crypto-js 4.2.1 (malware advisory GHSA-2x9r-6wxq-hrr7) whose postinstall script dropped a cross-platform remote-access trojan; WSO2 gives a window of about 00:21-03:15 UTC.
7. A CISA alert of 2026-05-28, "Supply Chain Compromises Impact Nx Console and GitHub Repositories", was seen as a title only (UNVERIFIED details).

Lessons for our rules:
- Exact pins plus a committed lockfile plus `npm ci` stop silent upgrades, but not a bad version chosen when the lock is created or updated. A cooldown covers that: incidents 1 and 6 were live for about 5 and 3 hours, so `min-release-age=7` would have kept a fresh lock off them.
- Install-time scripts were the execution path in incidents 3, 5 (lockfile tampering) and 6. No candidate needs install scripts (F22), so install with scripts off.
- Every `resolved` URL in package-lock.json must point to registry.npmjs.org, with an `integrity` field (incident 5). Never run "bot" repos from GitHub.
- Account takeover is the common root cause. Prefer packages published by trusted publishing with provenance, and treat a new version without provenance from a package that normally has it as a red flag (heuristic). Keep the signing key away from processes that run third-party code where practical (rule 1 class of victims).

## Recommendations for the security-auditor (preliminary, not approvals)

1. Runtime: pin Node **26.13.0** (Active LTS "Lithium", supported to 2029-04-30) on Windows and in the VPS image, and take each 26.x security release. Fallback: 24.22.2 (Maintenance, to 2028-04-30). 26.x became LTS only on 2026-10-28. Avoid 22.x for node:sqlite (Stability 1.1, warning).
2. Storage: prefer built-in `node:sqlite` over better-sqlite3 (no third-party native code). It is a Release Candidate (Experimental 1.2), not Stable, so pin Node exactly and keep storage behind one small module with tests. Use `PRAGMA journal_mode = WAL`, set `timeout`, `readBigInts: true`, and store u64 base units that can exceed 2^63-1 as TEXT (F10).
3. TypeScript: pin **6.0.3** while typescript-eslint is used (its range stops below 6.1.0); revisit TS 7 when typescript-eslint supports it. Type-check with `tsc --noEmit` in CI. Running `.ts` directly via type stripping is stable in 24/26 if the code stays erasable-only (F11); compiling with tsc is the alternative.
4. Prefer Node built-ins (global `fetch`, global `WebSocket`) before adding `undici` or `ws`. Prefer `@solana/kit` + `@solana-program/*` (provenance, trusted publishing, 0-3 deps each). Avoid web3.js v1 and the `@pump-fun/*` SDKs as dependencies for now: they pull web3.js v1, Anchor and spl-token, have no provenance, and the pinned agent-payments-sdk 1.0.7 has no repository field and a `"*"` native optional dependency. Prefer grammy over telegraf (no release since 2024-02-29).
5. npm (bundled 11.20.0 supports all of this), project `.npmrc`: `save-exact=true`, `engine-strict=true`, `ignore-scripts=true`, `min-release-age=7`, `allow-git=none`, `allow-remote=none`. If some package ever needs a script, the alternative to `ignore-scripts` is `strict-allow-scripts=true` plus a reviewed `allowScripts` list (`ignore-scripts` overrides both); npm 12 makes that policy the default. Install with `npm ci --ignore-scripts`; in CI also run `npm audit signatures` and `npm audit --audit-level=moderate`, and a check that every lock `resolved` URL starts with `https://registry.npmjs.org/` and has `integrity`. 5 candidates' latest versions are under 7 days old today (ws, vitest, @anthropic-ai/sdk, eslint, @solana/kit), so the cooldown would select their previous versions.
6. gitleaks: use the MIT release binary v8.30.1 (expected names `gitleaks_8.30.1_windows_x64.zip` / `gitleaks_8.30.1_linux_x64.tar.gz` from goreleaser defaults, UNVERIFIED; verify the SHA256 against the release checksums file). Pre-commit: a plain git hook running `gitleaks git --pre-commit --redact --staged --verbose` (no Python `pre-commit` tool needed). CI: run the same binary with `gitleaks git --redact --verbose` over full history (`fetch-depth: 0`). gitleaks-action is EULA software and needs a key for organization repos (free for personal repos), so the binary is simpler. Note gitleaks is now security-patch-only; Betterleaks was not evaluated.
